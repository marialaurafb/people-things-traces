# people-things-traces
Repo for the **People, Things, Traces** database and research website

This repo will contain the database I developed, and an additional website where I share my other research, notes and reflections on my practice as an art historian and digital humanist.

People, Things, Traces is a database I developed for my PhD thesis. It was created with Colonial Mexican painters in mind, but it can be expanded to consider any time or geography. The purpose of the conceptual model is to gather data about the connections between people, people and their things, and between things, while always keeping track of the sources from which each piece of information originates, hence 'traces'. At the same time, 'traces' evokes movement and space, which are also considered within this framework.
